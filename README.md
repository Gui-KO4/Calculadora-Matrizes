# Calculadora de Matrizes

Este projeto é uma calculadora de matrizes e vetores em C# que resolve um numero de operaçoes
e um jogo de batalha naval

## Group members of the project:
* Leandro Santos
* Guilherme Soares
* Henrique Carvalho
* Henrique Metelo

## Requirements:
* .NET 8.0 SDK or higher

## Funções Desenvolvidas
* Leitura de Matrizes
* Multiplicação por uma escalar
* Soma de Matrizes
* Multiplicação de matrizes
* Inversa de uma matriz 2x2
* Determinante de uma matriz 3x3
* A transposta de uma matriz
* Verificar se uma matriz é diagonal
* Verificar se uma matriz é Triangula
* Determinante de uma matriz 3x3
* Leitura de um vetor
* Soma de vetores
* Multiplicar vetores por uma constante
* Produto interno de dois vetores
* Jogo de batalha naval
* Listar vetores ou matrizes
